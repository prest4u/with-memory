# Security

With. stores facts in SQLite on the owner’s machine. Do not write secrets, cookies, tokens, or a minor’s attendance or individual performance into a fact.

If you find a vulnerability, contact the maintainer privately. Do not paste a live `memory.db` or a raw session into an issue. The public repository must not contain a real data directory or an unexpanded credential.

The data directory is local. It is never the Git remote.
