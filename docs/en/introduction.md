# Introduction

With. keeps memory on the machine and under the owner's OS account. SQLite is truth; Obsidian is optional and replaceable. Every harness shares the same CLI/stdio MCP contract instead of creating another private memory silo.

## A normal loop

1. The harness searches current facts inside its authorized scope.
2. It begins an assigned source run only when source consent exists.
3. It distills a short candidate; content policy runs before persistence.
4. The owner reviews it locally, resolves conflicts, and optionally supersedes an old fact.
5. SQLite commits atomically; optional Obsidian projection catches up independently.

This preserves both the current answer and an explicit historical chain without letting an automated harness silently redefine the present.

Use the paste-in [install](../../quests/en/install.md), [daily sync](../../quests/en/daily-sync.md), and [add harness](../../quests/en/add-harness.md) quests, or the [CLI/MCP reference](cli-mcp.md).

The command remains `eric-memory` because existing IDs, scripts, and MCP configurations are part of the v1 compatibility promise. The product name is With.
