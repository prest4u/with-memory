# Unified owner workflow

The former “simple tier” no longer exists as a separate storage mode. v1 has one security model: harnesses submit candidates and the owner reviews locally. The old `--tier simple` spelling remains accepted only for compatibility.

Use the [safe install quest](../../quests/en/install.md), then the [trusted daily sync quest](../../quests/en/daily-sync.md). Obsidian is optional. Never let an installer auto-accept a candidate, approve a guessed path, request administrator rights, or install a background task.

For backup, privacy, purge, and recovery, use the same production commands and documentation as a maintainer. There is no reduced-safety edition.
