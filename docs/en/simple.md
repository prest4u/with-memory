# Simple tier

You do not need a terminal. Give the full quest to the AI you already use and let it work.

## First time

1. Install [Obsidian](https://obsidian.md).
2. Put this folder on the machine (clone, zip, or a copy from someone else).
3. Open the AI you already use.
4. Paste [`quests/en/install.md`](../../quests/en/install.md) in full.
5. Answer what it asks: which tools, which folders. Paths must be complete. Do not say “Documents” and stop.
6. Open the vault it names. Start at the home note.

## Every later day

Paste [`quests/en/daily-sync.md`](../../quests/en/daily-sync.md) into any connected tool.

It will:

- search first, and not treat expired rows as current
- write one to three sentences
- deprecate the old row when the present has changed
- refresh the Obsidian home note

You only look at current / expired / folders / harnesses.

## A new AI tool

Do not reinstall. Paste [`quests/en/add-harness.md`](../../quests/en/add-harness.md) into the tool you have now.

## Do not

- Treat an Obsidian edit as the official present. The vault is a projection.
- Let the AI delete old memory. Expire it.
- Write passwords, secrets, or a minor’s attendance or individual performance into a fact.
- Give the AI administrator rights, or let it install a login item.
