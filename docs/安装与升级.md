# 安装与升级

## 支持形态

With. 安装在当前用户目录，不要求管理员权限，不自动修改 `PATH`，不启动守护进程，安装时也不联网。GA 目标为 macOS arm64/x86_64、Windows x86_64、Linux x86_64。只有同一 GitHub Release 同时包含原生平台签名、签名清单、SBOM 与 provenance 时，产物才算官方发行。

当前仓库仍是开发 checkout，不是 GA 二进制发行。

## 从源码安装

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade "pip==26.2.1"
.venv/bin/python -m pip install .
.venv/bin/eric-memory --data-dir "$HOME/eric-memory-data" init --no-obsidian
```

要启用 Obsidian 投影，去掉 `--no-obsidian`，或提供绝对 `--vault` 路径。旧版 `--tier simple|full` 在 v1 期间仍被接受，但只产生弃用提示，系统始终使用统一模式。

Windows 使用 `.venv\Scripts\python.exe` 和 `.venv\Scripts\eric-memory.exe`。数据目录应只归当前用户所有。`doctor` 会报告目录权限与系统磁盘加密状态。

## 初始化 principal

从本地 CLI 创建每个 harness：

```bash
eric-memory --data-dir /绝对路径/data harness add --key cursor --name Cursor --mcp-mounted
```

默认能力只有状态、获准 scope 的 active 检索、candidate 提交/读取自己的 candidate，以及分配来源的扫描。例外权限必须从本地 CLI 授予：

```bash
eric-memory --data-dir /绝对路径/data harness grant --key cursor --capability history:read
```

`fact:write`、`sync:run`、`file:search` 和 `manage` 都不是默认权限。

## 显式更新器

With. 不做后台更新检查：

```bash
eric-memory update check
eric-memory --data-dir /绝对路径/data update apply
```

`update apply` 只允许 GitHub HTTPS 资产，校验内置 Ed25519 信任根、签名清单、大小与 SHA-256，拒绝危险压缩路径，展示数据库迁移计划和备份位置，并要求输入准确版本确认。它安装到用户目录，不修改 `PATH`；schema 迁移仍需另行显式执行。

若发行公钥不存在，更新会安全失败。禁止绕过。

## 升级已有数据库

先只读规划：

```bash
eric-memory --data-dir /绝对路径/data migrate --plan
eric-memory --data-dir /绝对路径/data backup create
```

检查计划并验证备份后才执行：

```bash
eric-memory --data-dir /绝对路径/data migrate --apply
eric-memory --data-dir /绝对路径/data doctor
```

不要拿真实数据库的唯一副本测试迁移。RC 阶段只对副本操作；迁移 owner 的真实库需要单独、明确授权。

升级 pre-v2 数据库前请先读[迁移、备份与恢复](迁移备份与恢复.md)。
