# 安装任务（说明）

给任意 harness 粘贴的全文在 [`quests/安装任务.md`](../quests/安装任务.md)。英文在 [`quests/en/install.md`](../quests/en/install.md)。

正式发行是当前用户目录中的已签名原生 onedir 包；开发阶段也可从源码虚拟环境安装。任务只做：

1. 检查 Python 3.10+
2. 创建绝对数据目录（不覆盖已有库）
3. 可选写入 Obsidian 模板
4. 登记 principal，并通过独立 `source approve` 记录每个目录同意
5. 挂载带 `--principal KEY` 的 stdio MCP
6. 用 `doctor`、备份和 pending candidate 验收

不改全局 PATH（除非用户明确要求），不装守护进程，不要管理员，不自动 accept candidate。
