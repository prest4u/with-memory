# 安装任务（说明）

给任意 harness 粘贴的全文在 [`quests/安装任务.md`](../quests/安装任务.md)。英文在 [`quests/en/install.md`](../quests/en/install.md)。

安装物是文件夹，不是安装包。任务只做：

1. 检查 Python 3.10+
2. 创建绝对数据目录
3. 写入 Obsidian 模板
4. 询问并登记 AI 工具、资料夹
5. 挂 CLI；能挂 MCP 就挂，不能就只靠 CLI

不改全局 PATH（除非用户明确要求），不装守护进程，不要管理员。
