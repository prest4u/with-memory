# 完整档（给你）

简易档的全部约定仍然有效。这里只补维护者需要的部分。

## 本机布局

- 仓库：`/Users/eric/Documents/eric-memory`
- 默认数据目录：`/Users/eric/eric-memory-data`（`init` 时把 `~` 展开一次，之后只用绝对路径）
- 真值：`…/eric-memory-data/memory.db`
- 人看的库：默认 `…/eric-memory-data/vault`
- 旧 Holograph：`/Users/eric/.hermes/profiles/eric/memory_store.db`（只读导入源，不改、不删）

## 开发命令

```bash
cd /Users/eric/Documents/eric-memory
python3 -m unittest discover -s tests -v
python3 bin/eric-memory --data-dir /Users/eric/eric-memory-data init --tier full
python3 bin/eric-memory --data-dir /Users/eric/eric-memory-data import holograph \
  --source /Users/eric/.hermes/profiles/eric/memory_store.db
python3 bin/eric-memory --data-dir /Users/eric/eric-memory-data verify \
  --expect-query 刘昱铄 --expect-query 青云
python3 bin/eric-memory --data-dir /Users/eric/eric-memory-data sync
```

MCP 入口：`mcp/server.py`（stdio，`Content-Length` 帧）。工具名与 CLI 动词对齐。

## 导入规则

- 迁 content / category / tags / entities / trust
- 标签里已有 `status:deprecated` 的保持过期
- **没有** `status:` 的条目标 `active`，`as_of` 为导入日
- 导入时不猜测作废
- 以 `source_kind=import` + `source_ref=holograph:<id>` 去重，可安全重跑

导入成功前，旧 Holograph 继续可用。成功后，你自己的新写入改走本仓库。旧库留作归档。

## 检索

1. 实体名
2. 含中文：LIKE（多词 AND；中英混合会拆开）
3. 英文：FTS5，miss 后再 LIKE

默认 `status = active`。`--include-deprecated` 才看历史。

## 工具清单

`eric-memory harness catalog` 打印已知项。这不是封闭世界。新工具用「添加 AI 工具」任务，不重装内核。

每日同步只收割 `harvest_ok=1` 且有绝对 `session_root` 的登记项。未登记的目录不会被扫。

## Windows / Linux

仓库里有步骤，见各 quest。你不必须在那两套系统上实测。注意：

- Windows：`py -3`，数据目录用 `%USERPROFILE%\eric-memory-data`
- Linux：`python3`，数据目录用 `$HOME/eric-memory-data`
- 都不要用管理员 / root 安装
