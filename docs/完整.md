# 维护者工作流

旧“完整档”现在与 owner 使用同一套 schema、候选审阅和事实检索流程；`--tier full` 只是弃用兼容参数。

维护者额外负责迁移/回滚测试、source consent、双语检索黄金集、10 万规模基准、四平台冻结构建、签名/公证、SBOM/provenance、真实 harness 测试结果和独立审阅。先读[架构](en/architecture.md)、[迁移与恢复](迁移备份与恢复.md)和[发布流程](发布流程.md)。

开发必须使用隔离虚拟环境和合成数据库：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade "pip==26.2.1"
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/ruff check .
.venv/bin/mypy
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/evaluate_search.py
.venv/bin/python scripts/benchmark.py --facts 10000 --files 5000
```

禁止对 owner 的真实库运行 `mac_gate`、迁移 apply、restore 或破坏性 QA。正式候选必须由新的独立 reviewer 审阅，并将测试和审查记录对应到同一不可变 commit。
