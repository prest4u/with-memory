# 完整档（维护者）

简易档的全部约定仍然有效。这里只补维护者需要的部分。

## 本机布局

`init` 时把 `~` 或 `%USERPROFILE%` 展开一次，之后只用绝对路径。

- 仓库：本项目的克隆
- 默认数据目录：macOS/Linux 为 `$HOME/eric-memory-data`，Windows 为 `%USERPROFILE%\eric-memory-data`
- 真值：数据目录里的 `memory.db`
- 人看的库：默认 `vault`，或 `init --vault` 指定的绝对路径
- 旧 Holograph：用户给出的绝对路径，常见为 `$HOME/.hermes/profiles/<name>/memory_store.db`（只读导入源，不改、不删）

数据目录不要提交进 Git。

## 开发命令

```bash
cd /ABS/with-memory
python3 -m unittest discover -s tests -v
python3 scripts/repo_check.py
python3 bin/eric-memory --data-dir "$HOME/eric-memory-data" init --tier full
python3 bin/eric-memory --data-dir "$HOME/eric-memory-data" import holograph \
  --source "$HOME/.hermes/profiles/NAME/memory_store.db"
python3 bin/eric-memory --data-dir "$HOME/eric-memory-data" verify \
  --expect-query "示例名"
python3 bin/eric-memory --data-dir "$HOME/eric-memory-data" sync
```

MCP 入口：`mcp/server.py`（stdio，`Content-Length` 帧）。工具名与 CLI 动词对齐。

本机已有数据目录时再跑 `python3 scripts/acceptance_check.py`。CI 只跑单元测试和 `repo_check.py`。

## 导入规则

- 迁 content / category / tags / entities / trust
- 标签里已有 `status:deprecated` 的保持过期
- **没有** `status:` 的条目标 `active`，`as_of` 为导入日
- 导入时不猜测作废
- 以 `source_kind=import` + `source_ref=holograph:<id>` 去重，可安全重跑

导入成功前，旧 Holograph 继续可用。成功后，新写入改走本仓库。旧库留作归档。

## 检索

1. 实体名
2. 含中文：LIKE（多词 AND；中英混合会拆开）
3. 英文：FTS5，miss 后再 LIKE

默认 `status = active`。`--include-deprecated` 才看历史。

## 工具清单

`eric-memory harness catalog` 打印已知项。这不是封闭世界。新工具用「添加 AI 工具」任务，不重装内核。

每日同步只收割 `harvest_ok=1` 且有绝对 `session_root` 的登记项。未登记的目录不会被扫。

## Windows / Linux

同一套合同，见 [windows-linux.md](windows-linux.md)。你不必须在那两套系统上实测。

- Windows：`py -3`，数据目录用 `%USERPROFILE%\eric-memory-data`
- Linux：`python3`，数据目录用 `$HOME/eric-memory-data`
- 都不要用管理员 / root 安装
