# 每日同步任务（说明）

全文：[`quests/每日同步任务.md`](../quests/每日同步任务.md)。英文：[`quests/en/daily-sync.md`](../quests/en/daily-sync.md)。

同步不是静默后台。由用户（或用户自己设的自动化）显式发起。

只处理 `source approve` 后仍有效且分配给当前 principal 的目录。不把整段会话写入数据库；普通 harness 只提交 candidate，由本地用户 review。
