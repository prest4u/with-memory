# 统一的 owner 工作流

旧“简易档”不再是独立存储模式。v1 只有一套安全模型：harness 交 candidate，owner 在本地审阅。旧 `--tier simple` 只为兼容保留。

先使用[安全安装任务](../quests/安装任务.md)，日常使用[可信同步任务](../quests/每日同步任务.md)。Obsidian 可选。禁止让安装代理自动 accept candidate、批准猜测路径、索取管理员权限或安装后台任务。

备份、隐私、purge 与恢复和维护者使用同一套生产命令；不存在降低安全标准的版本。
