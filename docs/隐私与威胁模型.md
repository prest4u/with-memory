# 隐私与威胁模型

## 受保护资产

With. 保护事实正文、candidate 正文、实体、来源 locator、文件路径与摘要、scope 关系、审计元数据和备份。SQLite 是真值；启用的 Obsidian Vault 是另一份明文投影。

## 系统保护范围

系统保护依赖操作系统账户与磁盘加密。With. 在 MCP 内执行最小权限，同时提供文件权限、来源同意、脱敏日志、签名更新和内容策略。它不承诺抵御同账户任意 shell、系统管理员、离线磁盘取证或已被攻陷的 OS 依赖。

应启用 FileVault、BitLocker 或 LUKS。With. 不实现应用层数据库加密。`doctor` 会在无法验证磁盘加密时告警；这个告警并不一定能证明所有平台都未加密。

## MCP principal 与 scope

除 legacy 外，每个 MCP 配置都必须传 `--principal KEY`，`tools/list` 会按能力过滤。普通 harness 默认只有：

- `status:read`
- 获准 active scope 的 `fact:search`
- `candidate:submit`
- `candidate:read-own`
- 分配来源的 `source:scan`

历史、直接事实写入、sync 和文件搜索都要从本地 CLI 额外授权。兼容能力 `manage` 允许 harness 列出客户端身份；导入、文件索引管理和客户端注册仍只供本地管理员使用，其他 principal 即使获授 `manage` 也不会看到这些工具。project/workspace 查询必须提供准确 key。`scope=user` 代表该 principal 获准的所有 scope，不会绕过 ACL；状态、scope 与 ACL 过滤都先于排名。

按事实 ID 查询历史时，返回链中的每条事实都必须同时满足 `fact:search` 和 `history:read`。撤销来源会拒绝该来源尚未接受的候选并清除正文。查看或审阅前会清理到期候选，接受候选的写事务还会重新检查有效期及来源授权。

`legacy` principal 只能读取状态和 active 检索。旧 `memory_add` / `memory_deprecate` 会返回稳定的 `PERMISSION_REQUIRED`。

## 内容策略

写入事实或候选前，With. 会检测凭据、私钥、高熵 token、cookie、长篇原文，以及疑似未成年人到课或个体表现。

- 明确禁止内容直接拒绝，原文不会进入 fact、candidate、日志或 audit。
- 疑似内容只产生脱敏 quarantine，必须脱敏后重新提交。
- candidate 被接受后会删除 candidate 正文；正文只存在于不可改写的 fact。
- rejected / expired candidate 会立即清除正文，只保留不可重建摘要、原因和审计元数据。

MCP 没有跳过禁止类别的参数。

## 来源

只有本地交互式 `source approve` 能授权来源。系统保存 canonical root、include/exclude、文件类型、单文件上限、所属 harness 和同意事件。OS 根目录被禁止；批准整个主目录必须输入完整 canonical path。扫描用 `lstat`，跳过所有符号链接，并再次校验 containment。

主库的来源索引只保存路径、摘要、文件状态、游标和 candidate 指针，不保存文件或会话正文。撤销来源会让未完成 run 失效，清除文件索引和游标，并把既有事实标记为来源已撤销。

可选的[工作上下文](工作上下文.md)模块只有在管理员明确允许临时正文存储、并授予项目权限后，才会把选定文档保存在独立缓存。缓存不进入 With. 管理的备份、支持包、事实导出或 Obsidian 投影。每次读取检查当前项目授权与来源同意记录；过期内容立即停止返回，物理清理由索引或本地清理命令执行。

凭据、未成年人个体信息及可识别的完整会话仍会被拒绝。该模块不执行命令、不联网，也不自动采集会话。来源撤销会尝试清除缓存；如果临时库损坏导致清理失败，结果会说明撤销已生效并提示本地重置。恢复备份和紧急清除会先移除整个临时库。

## 日志与支持包

结构化日志带 operation UID，但默认不含事实正文或完整路径。`support-bundle` 只导出版本、schema、脱敏配置与日志；默认不含事实和路径。禁止把真实数据库或原始会话贴到公开 issue。

## 网络与供应链

没有遥测，只有显式更新命令联网。更新 URL 仅允许 GitHub HTTPS，重定向在请求前逐个校验，压缩包有大小与路径安全限制，最终资产必须匹配 Ed25519 签名清单。缺少信任根或签名时会直接停止。
