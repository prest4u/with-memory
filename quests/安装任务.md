# 任务：安装本机记忆系统

你是安装代理。用户把这个仓库放到了他们的电脑上。按下面做完，不要发挥成「装一个 App」或「装开机守护」。

## 硬限制

- 不要管理员 / sudo / 以管理员打开终端。
- 不要改系统 PATH，除非用户明确说「可以」。
- 不要安装守护进程、登录项、计划任务（除非用户后来自己要每日自动化，且那是另一份任务）。
- 不要连接云，不要创建 GitHub / Gitee 仓库。
- 不要修改用户已有的 Holograph / Hermes `memory_store.db`。
- 路径一旦写入配置，必须是绝对路径。禁止把未展开的 `~` 写进数据库或脚本。
- 只调用本仓库的 `bin/eric-memory` 或 `python3 -m eric_memory`。禁止私自 `INSERT` SQL。

## 0. 找到仓库

仓库根目录应有 `bin/eric-memory`、`src/eric_memory/`、`quests/`。

若当前工作区不是这个根，先问用户仓库在哪，再 `cd` 进去。下面用 `REPO` 表示该绝对路径。

## 1. 检查运行时

macOS / Linux：

```bash
python3 --version
```

Windows：

```bat
py -3 --version
```

需要 Python 3.10+。没有就停，告诉用户先装官方 Python，不要用管理员装一堆依赖。本系统零第三方包。

## 2. 询问（必须问，不要猜）

用用户的语言问，并等回答：

1. **档位**：简易（默认，客户）还是完整（维护者）？
2. **数据目录**：默认 macOS/Linux 为 `$HOME/eric-memory-data`，Windows 为 `%USERPROFILE%\eric-memory-data`。要改就让用户给绝对路径。
3. **Obsidian 库**：默认放在数据目录下的 `vault`。若用户已有库，必须是绝对路径。
4. **正在用的 AI 工具**（可多选，不是封闭名单）：
   - Kimi Code
   - Qwen Code
   - 通义灵码 / Qoder
   - WorkBuddy
   - CodeBuddy
   - ZCode（GLM 常常只是模型，不是独立工具；只有真在用 ZCode 才勾）
   - MiniMax Code
   - Trae / TraeCode
   - Comate / 文心快码
   - OpenClaw
   - Cursor
   - Claude Code / Codex / OpenAI
   - Hermes
   - Grok / xAI
   - 其他（请用户写出名字）
5. 对每一个勾选的工具：有没有**用户点头**的会话目录？有则只要绝对路径；没有就只挂 CLI/MCP，**不要全盘找**。
6. **资料夹**：哪些文件夹以后允许被索引？没有就跳过。有就必须是绝对路径。
7. 大陆网络提示（让用户知情即可，不要替他们做翻墙）：
   - Kimi C 端新购曾暂停，以本机是否已装为准
   - Cursor / OpenAI / Grok 在大陆可能受限
   - 工具列表可以以后用「添加 AI 工具」任务再补

## 3. 初始化

把用户的 `~` 或 `%USERPROFILE%` 在这一步展开成绝对路径，再执行。

macOS / Linux：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" init --tier simple --vault "$VAULT"
```

完整档把 `--tier simple` 换成 `--tier full`。

每有一个资料夹：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" index-files --folder "$FOLDER"
```

Windows（PowerShell）：

```powershell
py -3 "$REPO\bin\eric-memory" --data-dir "$DATA" init --tier simple --vault "$VAULT"
```

## 4. 登记工具

对用户勾选的每一项：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" harness add --key "$KEY" --name "$NAME"
```

仅当用户给出了会话目录并且明确允许「同步时可索引该目录」时，才加：

```bash
--session-root "$ABS_SESSION" --harvest
```

能在该工具里挂 MCP 时再加 `--mcp-mounted`，并把 `mcp/server.py` 写成该工具的 stdio 配置（模板见 `adapters/`）。Cursor 写 `.cursor/mcp.json` 或用户级 `mcp.json`；Hermes 写 `mcp_servers.eric-memory`。挂不上就跳过，CLI 仍然可用。只把旗标标成已挂、却不写配置文件，算没挂上。

`KEY` 优先用清单里的键：`kimi` `qwen` `lingma` `workbuddy` `codebuddy` `zcode` `minimax` `trae` `comate` `openclaw` `cursor` `claude` `codex` `hermes` `grok` `other`。

## 5. 完整档才做的导入

仅当用户选了完整档，并且本机存在旧库：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" import holograph \
  --source /Users/eric/.hermes/profiles/eric/memory_store.db
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" verify \
  --expect-query 刘昱铄 --expect-query 青云
```

旧库只读。导入失败就停，不要改旧库。

## 6. 同步投影并验收

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" sync
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" status
```

然后：

1. 告诉用户用 Obsidian 打开 `$VAULT`，先点「记忆首页」。
2. 指给他们看四个入口：现行 / 已过期 / 资料夹 / 已接工具。
3. 把「以后每天用」的任务路径告诉用户：`quests/每日同步任务.md`。
4. 把本仓库的 `skills/严格技能.md` 交给正在用的 harness（能放进项目技能就放；不能就每次同步时提醒它先读）。

## 7. 失败时

- Python 太旧：停。
- 路径含未展开的 `~`：展开后再写。
- 用户拒绝给会话目录：登记工具但不加 `--harvest`。
- 某家工具没法挂 MCP：写进备注，继续。

做完用中文向用户汇报：数据目录、Vault 路径、已登记工具、未挂上的部分。不要说「已经全自动后台更新」。
