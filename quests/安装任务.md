# 任务：安全安装 With.

你是本地安装代理。先读 `skills/严格技能.md`。不使用 sudo/管理员，不修改 PATH，不安装守护进程、计划任务或云服务，也不触碰已有真实库，除非用户给出准确路径并明确授权对应操作。

## 1. 收集决定

必须等待用户回答：

1. 数据目录绝对路径（默认 macOS/Linux：`$HOME/eric-memory-data`；Windows：`%USERPROFILE%\eric-memory-data`）。
2. 是否启用 Obsidian；启用时给 Vault 绝对路径。
3. 正在使用的 harness 及每个稳定 key。
4. 哪些目录允许作为 source；逐个给绝对路径、所属 harness、include/exclude、类型和单文件上限。未知路径不搜索。
5. 是否有旧数据库要做只读迁移计划或只读 Holograph 导入。没有就跳过。

v1 只有统一模式，不再询问 simple/full。旧 `--tier` 只是兼容参数。

## 2. 选择入口

正式 GA 应优先使用已验证的原生发行包；校验签名清单、平台签名、SHA-256 与 provenance。当前源码安装：

```bash
python3 -m venv "$REPO/.venv"
"$REPO/.venv/bin/python" -m pip install --upgrade "pip==26.2.1"
"$REPO/.venv/bin/python" -m pip install "$REPO"
```

Windows 使用 `$REPO\.venv\Scripts\python.exe`。需要 Python 3.10+。依赖安装失败就停，不要换成不受信任镜像。

## 3. 初始化

先把环境变量展开成绝对路径：

```bash
"$ERIC_MEMORY" --data-dir "$DATA" init --vault "$VAULT"
```

不使用 Obsidian 时加 `--no-obsidian`。若目标路径已有数据库，停止初始化，先运行只读 `status` / `migrate --plan`。

## 4. 注册身份与批准来源

每个 harness：

```bash
"$ERIC_MEMORY" --data-dir "$DATA" harness add \
  --key "$KEY" --name "$NAME" --mcp-mounted
```

每个用户明确同意的来源必须另行批准：

```bash
"$ERIC_MEMORY" --data-dir "$DATA" source approve "$SOURCE" \
  --harness "$KEY" --include "*.md" --exclude ".git" --type md
```

禁止用 `index-files` 或 `harness add --harvest` 绕过 `source approve`。OS 根目录不可批准；完整主目录必须让用户输入 canonical path 确认。

MCP 配置必须是 stdio 且携带身份：

```text
eric-memory --data-dir /ABS/data mcp --principal KEY
```

不知道 host 语法时读 `adapters/generic-mcp.md`；不配置 HTTP。

## 5. 旧数据

对 pre-v2 库先只读：

```bash
"$ERIC_MEMORY" --data-dir "$DATA" migrate --plan
```

任何真实迁移都必须先 `backup create` / `backup verify` 并重新向用户确认。RC 只对副本执行 `migrate --apply`。Holograph 只能用用户提供的绝对路径只读导入。

## 6. 验收

```bash
"$ERIC_MEMORY" --data-dir "$DATA" doctor
"$ERIC_MEMORY" --data-dir "$DATA" backup create
"$ERIC_MEMORY" --data-dir "$DATA" candidate add \
  --content "安装验收 candidate，必须经本地 review 才能生效。" --entities With
"$ERIC_MEMORY" --data-dir "$DATA" candidate list
```

不要自动 accept 测试 candidate；让用户打开 `review` 决定。最后汇报 data/Vault、principal、已批准 source、未挂 MCP、备份路径和 doctor 警告。不要声称后台自动同步。
