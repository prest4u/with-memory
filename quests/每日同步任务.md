# 任务：同步记忆

你在更新用户的本机记忆。先读仓库里的 `skills/严格技能.md`，再行动。

## 硬限制

- 只调用本仓库 CLI 或 MCP。禁止私自改 `memory.db`。
- 开工先 `search`。默认结果里的过期条不当现行。
- 写入 1–3 句：是什么 / 在哪 / 状态 / 下一扇门。
- 有矛盾：先 `add` 新条，再 `deprecate` 旧条（或 `add --supersedes`）。
- 不写凭据、密钥、未成年人到课或个体表现、整段会话。
- 只读用户已经点头并登记的会话目录。不要全盘扫描。
- 不要删除事实。`purge` 不在本任务范围。

## 0. 定位

找到仓库根 `REPO` 与数据目录 `DATA`（常见：macOS `$HOME/eric-memory-data`）。若不确定：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" status
```

若 `status` 失败，改走「安装任务」，不要自己新建另一套库。

## 1. 开工检索

针对今天要处理的主题（用户消息里的人名、项目、文件）：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" search "$QUERY" --scope user
```

需要历史时才加 `--include-deprecated`。

作用域：

- 一般日常：`--scope user`
- 只看某项目：`--scope project --project 项目名`
- 只看某工作区：`--scope workspace --workspace 绝对路径或标签`

## 2. 读取已点头的源（可选）

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" harness list
```

只打开 `harvest_ok=true` 且 `session_root` 非空的目录。从中抽取**指针**，不要把聊天记录粘进事实。

## 3. 写入 / 作废

现行变化：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" add \
  --content "一句话事实。路径用绝对路径。状态写现行。" \
  --entities "实体1,实体2" \
  --category project
```

取代旧条：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" add \
  --content "新的现行说法。" \
  --supersedes OLD_ID
```

或：

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" deprecate OLD_ID \
  --superseded-by NEW_ID --reason "被新现状取代"
```

## 4. 更新给人看的窗口

```bash
python3 "$REPO/bin/eric-memory" --data-dir "$DATA" sync
```

这会重建 Obsidian 的「记忆首页 / 现行 / 已过期 / 资料夹 / 已接工具」，并重索引已登记资料夹与已点头会话根。文件只留下路径，不把正文变成事实。

## 5. 向用户交代

用中文列：

- 搜了什么，命中哪些现行条
- 新写了哪些 `#id`
- 作废了哪些 `#id`，被谁取代
- Obsidian 首页是否已更新
- 有没有没把握、需要用户拍板的矛盾

Windows 将 `python3` 换成 `py -3`，路径改用反斜杠或引号包住的绝对路径。
